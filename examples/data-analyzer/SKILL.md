# 数据分析专家（Data Analyzer）

> **设计哲学**: Mixed型（混合型）——工具脚本（数据清洗/指标计算/统计检验）+ 方法论（归因框架/分析模板）结合。脚本做确定性计算，AI做分析判断。

> **预加载**: 触发后先确认分析类型和数据来源，再读取对应的references文档和运行脚本。

## 工作流程（5步）

### 第1步：确认分析需求（高自由度）
- 确认分析类型（清洗/异动/漏斗/留存/实验/综合）
- 确认数据来源（CSV文件/数据库/API）
- 确认分析目标（回答什么问题）
- 确认时间范围和维度

### 第2步：数据加载与清洗（低自由度）
```bash
python3 scripts/clean_data.py input.csv -o cleaned.csv \
  --drop-na --remove-duplicates --normalize-dates
```
- 必须运行清洗脚本，不允许直接分析原始数据
- 清洗后必须验证：行数/列数/缺失值/异常值

### 第3步：指标计算（低自由度）
```bash
python3 scripts/calc_metrics.py cleaned.csv \
  --metrics "pv,uv,conversion_rate,avg_order_value" \
  --group-by "date,channel" -o metrics.json
```
- 所有指标必须用脚本计算，不允许LLM手算
- 指标结果必须验证：总和/均值/极值是否合理

### 第4步：分析判断与归因（AI核心工作，高自由度）
基于脚本计算的指标，AI做：
- **异动归因**：使用维度拆解法（按渠道/地区/用户群拆解），定位异动来源
- **漏斗分析**：识别流失最大的环节，分析流失原因
- **留存分析**：识别留存拐点，分析留存差异
- **实验分析**：判断统计显著性（p值/置信区间），评估实验效果

**归因方法论（必须使用）**：
1. **维度拆解法**：将总指标按维度拆解，找到贡献最大的维度
2. **对比法**：与历史同期/目标/竞品对比
3. **漏斗法**：从用户旅程的每个环节分析流失
4. **分群法**：按用户特征分群，找到差异最大的群体

### 第5步：输出分析报告（低自由度）
必须包含：
1. 核心结论（一句话）
2. 数据概览（关键指标+趋势）
3. 分析过程（归因逻辑+证据）
4. actionable建议（具体可执行）
5. 数据来源和计算方法（可追溯）

## Gotchas（常见坑）

1. **不清洗数据直接分析**：原始数据有缺失值/异常值/重复数据，直接分析会得出错误结论
2. **相关当因果**：A和B相关不代表A导致B，必须排除混淆变量
3. **忽略样本量**：小样本的波动很大，不能基于少量数据下结论
4. **只看平均值不看分布**：平均值可能掩盖分布的差异（如贫富差距）
5. **过度拟合**：在数据中找不存在的规律，特别是维度很多时
6. **不验证计算**：LLM手算指标容易出错，必须用脚本计算并验证
7. **报告太技术化**：业务方看不懂的分析报告没有价值，要用业务语言表达
8. **忽略时间因素**：同比/环比/趋势比单时点数据更有意义
