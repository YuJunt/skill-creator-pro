# 每步通过标准（Step Standards）

> 本文档详细说明每个步骤的通过标准，防止LLM表面满足（如"我读了文档"但只读了几行）。用`--quality`参数记录质量指标，gate命令自动检查是否达标。

---

## 通过标准表

| 步骤 | 通过标准 | 记录方式 |
|------|---------|---------|
| **读文档** | 必须引用≥1处具体内容（不能只读标题） | `track --type doc --quality '{"quotes":2}'` |
| **规范校验** | 必须0高优先级问题 | `track --type script --quality '{"high_issues":0}'` |
| **深度审计** | 必备层必须100%通过 | `track --type script --quality '{"required_pass":1.0}'` |
| **输出校验** | 必须0问题 | `track --type script --quality '{"issues":0}'` |
| **端到端测试** | 通过率必须≥80% | `track --type script --quality '{"pass_rate":0.9}'` |

---

## 未达标处理

**未达标时**：gate命令会报错，不能交付。这防止了LLM表面满足。

### 常见表面满足模式

1. **"我读了文档"**：但只读了标题，没有引用具体内容 → 通过标准要求引用≥1处
2. **"校验通过了"**：但有高优先级问题被忽略 → 通过标准要求0高优先级
3. **"审计完成了"**：但必备层有未达标项 → 通过标准要求必备层100%
4. **"测试通过了"**：但通过率只有50% → 通过标准要求≥80%
