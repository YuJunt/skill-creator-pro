# 技能创建输出格式模板

> 4种交付格式的完整模板，按需加载。SKILL.md中只保留摘要，详细模板在此。

---

## 1. 新建技能交付

```
## 技能创建完成：{skill-name}

**路径**: {path}
**设计哲学**: {capability/process/mixed}
**结构**: SKILL.md + scripts/ + references/ + examples/
**36项达标**: {X}/36 ({Y}%)，加权{Z}/53
**必备层**: {X}/20（必须全部达标）
**待完善**: {列出缺口}

✅ 已通过规范校验
✅ 已通过深度审计
⚠️ 建议：端到端实测验证
```

---

## 2. 优化技能交付

```
## 技能优化完成：{skill-name}

**路径**: {path}
**优化前**: {X}/36 ({Y}%)
**优化后**: {X}/36 ({Y}%)
**修复问题**: {列出修复的问题}
**新增功能**: {列出新增的功能}
**待完善**: {列出剩余缺口}

✅ 已通过规范校验
✅ 已通过深度审计（回归验证）
✅ 未引入新问题
```

---

## 3. 评审报告交付

```
## 技能评审报告：{skill-name}

**总体评分**: {X}/36 ({Y}%)
**加权评分**: {Z}/53 ({W}%)
**等级**: 优秀/良好/合格/不合格

### 三层得分
| 层级 | 达标/总数 | 权重 | 得分率 |
|------|----------|------|--------|
| 必备层 | X/20 | ×2 | XX% |
| 推荐层 | X/10 | ×1 | XX% |
| 可选层 | X/6 | ×0.5 | XX% |

### 高优先级问题（必备层缺失，必须修复）
1. {问题} → {修复建议}

### 中优先级问题（推荐层缺失，建议修复）
1. {问题} → {修复建议}

### 低优先级问题（可选层缺失，按需添加）
1. {问题} → {优化建议}
```

## 4. 端到端测试报告交付

```
## 技能端到端测试报告：{skill-name}

**测试日期**: {date}
**测试版本**: {version}

### 测试结果汇总
| 测试维度 | 用例数 | 通过 | 失败 | 通过率 |
|---------|--------|------|------|--------|
| 触发测试 | X | X | X | XX% |
| 模式测试 | X | X | X | XX% |
| 边界测试 | X | X | X | XX% |
| 质量测试 | X | X | X | XX% |

### 失败用例详情
1. {用例描述} → {实际结果} → {修复计划}

### 结论
{通过/不通过，建议}
```

---

**使用方法**: 根据交付场景选择对应模板，填充占位符。所有交付必须包含校验状态（规范校验+深度审计）。
**版本**: v1.0
