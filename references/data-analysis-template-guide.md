# 数据分析型技能模板指南

> 本文档是数据分析型技能的专业模板指南，适用于业务数据分析、指标计算、趋势预测、评分排序等需要确定性计算+AI决策的技能。

---

## 一、核心特点

| 维度 | 说明 |
|------|------|
| 设计哲学 | 混合型（Mixed）——工具脚本（确定性计算）+ 方法论（分析方法论+决策树）结合 |
| 核心能力 | 数据采集→指标计算→决策树推荐→AI深度分析→方案推荐输出→输出校验→云端同步 |
| 关键约束 | 脚本只做确定性计算，AI做分析决策；严格遵守职责边界 |
| 典型场景 | 业务数据分析、指标计算、趋势预测、评分排序 |

## 三、工作流设计（三段式管道）

### 管道一：start（数据采集+指标计算+决策树推荐）
- 通过标准：数据≥30条，指标≥30项，决策树7步全走

### 管道二：continue（AI深度分析+推荐方案+输出校验+云端写库）
- 通过标准：AI分析5个问题全答，推荐方案三层结构，输出校验0问题，云端同步必须成功

### 管道三：settle（结果结算+复盘+经验提取）
- 通过标准：结果核对准确，复盘6个问题全答，经验提取并写入经验库

## 四、Gotchas（真实踩过的坑）

1. **脚本越权做分析决策**：脚本只输出候选方案+评分+理由，AI做最终决策
2. **数据采集失败没有降级**：官方API→第三方API→本地缓存三级降级
3. **决策树只走2步就给结论**：用--quality参数记录{"steps":7}，gate命令检查
4. **云端写入失败没有备份**：写入失败时自动备份到本地backup/目录
5. **多品类共用表串台**：自动注入"品类"字段，读取时按品类过滤
6. **路由行格式不统一**：统一格式，用runtime_guard.py route命令校验
7. **模板中的花括号未转义**：templates.py中{模式}必须转义为{{模式}}
